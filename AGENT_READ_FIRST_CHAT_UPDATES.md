## 2026-09-18 — Chat-derived updates

### Experience and visual direction

The project should not present agent systems as static diagrams wrapped in a generic AI aesthetic.

Current visual/interaction direction:
- use a more distinctive header typeface rather than a generic AI-looking font,
- use glowing borders where appropriate,
- allow selected borders or signals to blink or animate,
- use animation as a storytelling tool across the whole experience, not only inside diagrams,
- let words or interface elements light up directionally to communicate flow or causality,
- make scroll interactions reveal system behavior,
- design moments where the page reacts in ways users expect and also in ways that demonstrate how capable modern devices/frameworks have become.

Status: **approved design direction**.

### Product principle

Animation should communicate system behavior, sequence, relationship, and causality.

Avoid decorative motion that does not help the user understand the agent system.
