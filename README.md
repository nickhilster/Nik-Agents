# Nik + Agents

An evidence-first view of how Nikhil Khedkar works with AI systems in practice.

This project is not a catalog of AI tools or agent endorsements. It documents how different systems are selected, tested, routed, challenged, and combined around real work.

## Core idea

**Different problems require different systems.**

The page distinguishes between:
- advertised product role
- observed working role
- verified artifact evidence
- agent statements
- human-recalled workflow context
- inference / unresolved connections

## Primary case studies

1. **Nik + Agents email thread** — iterative convergence through bounded context, disagreement, and verification
2. **LTB Buddy** — multi-agent product, clinic, voice, governance, and outreach workflow
3. **RyFine** — flagship TeamBotics product; implementation, media pipeline, security hardening, and routing
4. **BoardyAnimated** — testing and repurposing a product beyond its marketed category
5. **Neural Breach** — rapid creative production across model tiers and human polish
6. **Symphony / Maestro** — routing by cost, capability, model, and connected services

Secondary examples include 108 Ganesha, Reliability OS, and RyFine security review.

## Design principle

A reader should understand the operating model in under 90 seconds. Deep evidence stays available, but collapsed by default.
