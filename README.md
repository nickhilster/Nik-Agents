# Nik + Agents

An evidence-first view of how Nikhil Khedkar selects, tests, routes, and combines AI systems around real work.

This is not a catalog of AI tools or agent endorsements. It documents how different systems are selected, challenged, combined, and replaced around real projects.

## Core idea

**Different problems require different systems.**

The page separates:
- advertised product role
- observed working role
- verified artifact evidence
- agent statements
- human-recalled workflow context
- unresolved / unverified connections

## Primary cases

1. **LTB Buddy** — high-stakes product, clinic, voice, governance, and outreach workflow
2. **RyFine** — TeamBotics flagship; implementation, video production, security hardening, and routing
3. **BoardyAnimated** — product curation beyond the marketed “superconnector” surface
4. **Neural Breach** — rapid creative production across model tiers and human polish
5. **Symphony / Maestro** — model literacy, connected services, credit economics, and routing
6. **Nik + Agents email thread** — iterative convergence through bounded context, disagreement, correction, and verification

Secondary proof points include **108 Ganesha**, **Reliability OS**, and the **RyFine security review**.

## Presentation rules

A reader should understand the operating model in under 90 seconds.

Deep evidence is available through collapsed drawers. Every evidence item carries a provenance class:

- **Verified artifact** — repo, commit, PR, file, deployed page, test, or recorded asset
- **Agent statement** — what an agent directly handled or could inspect
- **Human context** — workflow context supplied by Nik that is not preserved in the artifact surface
- **Unresolved** — plausible connection that the current record cannot prove

Uncertainty is preserved instead of being smoothed into a cleaner story.
